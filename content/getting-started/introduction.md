Welcome to the **Codex** — our internal lexicon of code snippets, logic blocks, and step-by-step recipes for the most common Zendesk Guide theme adjustments customers ask for.

Every entry has the *why*, the *how*, and a copy-pasteable code block. If a recipe doesn't exist yet, add it.

## What you'll find here

Each snippet page contains:

- A **use case** — the customer ask in plain language
- The **approach** — how to think about the change before writing code
- One or more **code blocks** with the theme file path they belong in (and a Copy button)
- **Gotchas** worth flagging
- **Related** entries to chain together
- **Commit history** showing how the snippet has evolved over time

## Where to start

If this is your first time using the Codex, read [How to use this codex](/how-to-use) — it covers the search palette, browsing, and how to add your own snippet.
